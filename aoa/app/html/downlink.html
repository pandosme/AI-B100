OTA Services and Ports
OTA downlinks let you read and change this device's settings from your LoRaWAN network server — no local network access needed. Each service listens on its own port, and the first byte of the payload is the command. The OTA Encoder and OTA Decoder buttons above give you JavaScript that builds valid frames and decodes replies in Node-RED or your own tooling.
The same command bytes work on every service
0x01 Get 0x02 Set / Execute 0x03 Capabilities 0x04 List
Where to start
Send Capabilities (0x03) first to learn what a service accepts. For scenes and alerts, List (0x04) gives you the identities to work with. Always Get (0x01) before you Set (0x02) — the write has to carry the fingerprint the read returned. Scene services edit scenes that already exist on the camera; they cannot create new ones.
